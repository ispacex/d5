# The D₅ problem: progress

Site: https://ispacex.github.io/d5/ (English); Russian: https://ispacex.github.io/d5/ru/

Progress on Problem 20.84 of the Kourovka notebook: is $D_5(G) \subseteq \gamma_4(G)$ for every group $G$?
The site shows what is proved and what is computed, the coverage maps, the searches, the timeline,
the open questions and the paper draft (`paper/d5.pdf`, `paper/d5-ru.pdf`).

This repository only holds the published pages. They are generated by `site/build_site.py` of
https://github.com/ispacex/dimension-subrings, which also holds all the code and the data of the
computations. The pages are not edited by hand.

Страницы собирает генератор `site/build_site.py` из https://github.com/ispacex/dimension-subrings;
там же весь код и данные вычислений. Вручную страницы не правят.
