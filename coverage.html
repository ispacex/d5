$2$-groups of class $3$: is $D_5(Q)=1$?

This is Problem 20.84 itself: by the reduction (Proposition 2.1), $D_5\subseteq\gamma_4$ for all groups if and only if $D_5(Q)=1$ for every finite $2$-group of class $3$. Class $3$ forces $d\le n-2$ at order $2^n$. No cell is open here any more: order $2^{11}$ is settled for every rank (Proposition 5.10).

$3$-groups: is $D_5(Q)=\gamma_5(Q)$?

This is the question of $3$-torsion in $D_5/\gamma_5$ (Tahara: the exponent divides $6$). The “paper” cells are closed thus: if $Q/\gamma_5$ is metabelian, then $D_5=\gamma_5$ by Gupta–Tahara, and a non-metabelian group of class $4$ and rank $d$ has order $\ge3^{d+5}$ (Proposition 6.5); for $d=2$ the factor $\gamma_2/\gamma_3$ is cyclic. The rest is the search up to $3^9$. Open cells are hatched: there the case of $Q/\gamma_2$ with at most one invariant $>3$ is proved (Theorem 6.8).
